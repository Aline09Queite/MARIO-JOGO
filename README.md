🍄 Jogo do Mario Clássico

Projeto desenvolvido durante meus estudos em programação no DevClub, inspirado no clássico jogo do Mario! 🎮

O objetivo foi colocar em prática meus conhecimentos em desenvolvimento web, criando um joguinho com movimentação e animações, trazendo um pouco da nostalgia dos jogos clássicos.

🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

✨ Funcionalidades e recursos

* Personagem com animações.
* Movimentação dos elementos do cenário.
* Animações utilizando CSS.
* Interatividade com JavaScript.
* Botão para reiniciar o jogo.

📚 Aprendizados

Com esse projeto, pude praticar e aprimorar meus conhecimentos em HTML, CSS e JavaScript, além de explorar animações e trabalhar a lógica de programação.

Cada projeto desenvolvido representa uma nova oportunidade de aprender, praticar e evoluir na minha jornada como desenvolvedora Front-End.
